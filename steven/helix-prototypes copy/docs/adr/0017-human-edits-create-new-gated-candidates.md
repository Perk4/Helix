# Human edits create new gated candidates

Before export, a human may request a redraft or component or tone change for a selected section without rerunning unaffected sections. The request opens a new, separately audited cycle of at most three Section Draft Candidates using the same Validated Claims and governed inputs, and each candidate repeats provenance compilation, study-specific Promptfoo evaluation, and Template Conformance Gates; the Review Scaffold advances and affected approvals become stale. Final export packages only exact approved artifact hashes and never redrafts content.
